# MMBA — Customer UI Specification

## Goal
Fast data entry with minimal cognitive load.

## Global search
Accept:
- name
- mobile
- customer code

A unique match opens the profile directly.

## Customer list
Columns:
- Name
- Mobile
- Status
- Last contact
- Last purchase
- City

Actions:
- View
- Edit
- Archive (permission controlled)

## Customer form
MVP fields:
- First name
- Last name
- Mobile
- Secondary mobile
- Phone
- National code
- Gender
- Birthday
- City
- Address
- Occupation
- Referral source
- Referred by
- Status
- Credit level
- Notes

## Profile
Header:
- Name
- Mobile
- Status
- Customer code

Quick actions:
- New call
- New task
- New note
- New contract (when available)

Main sections:
- Customer information
- Timeline
- Purchases/contracts summary
- Tasks
- Attachments

## Mobile-first
Call entry must be optimized for phone screens. After saving a call, the entry form resets for the next interaction.
